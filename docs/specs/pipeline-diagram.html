ETRM Factory · Architecture

Ticket-to-PR Pipeline

Deterministic Strands graph orchestrating LLM stages, a Claude Code execution runtime, and a long-term lessons loop through AgentCore Memory. Ends at a pull request, never a merge.

bounded feedback loop (iteration cap) memory write / semantic retrieval human decision point
  • Only Analyzer, Adversary, and Curator are Strands Agent LLM nodes. The Planner and Reviewer run as headless Claude Code sessions (plan mode) inside the runtime container; the Executor is a custom bridge node — a deterministic step that starts the Claude Code job in CodeBuild and waits. The implementation intelligence lives in the runtime, not the graph.
  • Edge conditions (suitable, objections, findings) are plain functions reading structured output from state.results — no LLM decides routing. Loops carry hard caps; on a cap hit the pipeline still proceeds, and the Curator records the unresolved findings, which are the highest-value lessons.
  • Retrieval is deterministic code, not an agent: embed the query, take the top-k above a similarity threshold, inject as clearly-delimited notes. Three consumers — planner (query: ticket), executor (query: plan), reviewer (query: the diff — reviewing blind first, and tagging lesson-prompted findings so the curator never reinforces a lesson from its own echo).
